\section{System Architecture Overview}
The \textbf{InternApplier} ecosystem connects two automated AI modules:
\begin{enumerate}[leftmargin=18pt, itemsep=2pt]
    \item \textbf{Cold Mailing Agent (\texttt{ColdMailingAgent/})}: Automatically parses 660+ founders/leads from the GES Mastersheet (Unicorns \& Soonicorns), conducts deep company intelligence to discover technical challenges, writes human cold emails without AI clichés, and schedules daily outreach strictly between \textbf{7:00 AM and 9:00 AM}.
    \item \textbf{Resume Builder (\texttt{Resume\_Builder/})}: Compiles strictly 1-page, ATS-optimized PDF resumes tailored via Gemini using the \textbf{Google XYZ Formula} (\textit{Accomplished [X], as measured by [Y], by doing [Z]}), and attaches them directly to outgoing recruiter emails.
\end{enumerate}

\section{Cold Mailing Agent — Command Line Reference}
Navigate to the directory before running:
\begin{verbatim}
cd F:\Intern\InternApplier\ColdMailingAgent
\end{verbatim}

\subsection{1. Dry Run / Preview Mode (\texttt{--dry-run})}
\textbf{Command:}
\begin{verbatim}
python mail_agent.py --dry-run
\end{verbatim}
\textbf{What it does:}
\begin{itemize}[leftmargin=14pt, itemsep=1pt]
    \item Randomly selects 5 unsent contacts across Unicorns and Soonicorns.
    \item Researches each company's domain, core platform, and specific data/ML challenges.
    \item Generates a human-sounding cold email draft connecting your IIT Kharagpur projects (FraudSentinel / Time-Series) for a \textbf{remote data intern} role.
    \item Compiles and links the tailored 1-page PDF resume.
    \item \textbf{Safety:} \textit{No emails are sent in this mode. Perfect for previewing output.}
\end{itemize}

\subsection{2. Automated Daily Scheduler Daemon (\texttt{--schedule})}
\textbf{Command:}
\begin{verbatim}
python mail_agent.py --schedule
\end{verbatim}
\textbf{What it does:}
\begin{itemize}[leftmargin=14pt, itemsep=1pt]
    \item Runs continuously in the background as an automated daemon.
    \item Automatically activates every morning during the \textbf{7:00 AM – 9:00 AM} sending window.
    \item Randomly shuffles the unsent contact pool and sends \textbf{15 to 20 emails daily} with anti-spam jitter (3--7 minutes delay between emails).
    \item Once the daily quota is reached (or at 9:00 AM), it sleeps automatically until the next morning at 7:00 AM.
    \item Records all sent emails in \texttt{logs/email\_log.csv} so no contact is ever emailed twice.
\end{itemize}

\subsection{3. Send Immediate Batch (\texttt{--now})}
\textbf{Command:}
\begin{verbatim}
python mail_agent.py --now
\end{verbatim}
\textbf{What it does:}
\begin{itemize}[leftmargin=14pt, itemsep=1pt]
    \item Bypasses the 7:00 AM – 9:00 AM time check and immediately sends today's batch of 15--20 random emails with safety jitter.
\end{itemize}

\textbf{What it does:}
\begin{itemize}[leftmargin=14pt, itemsep=1pt]
    \item Performs instant company intelligence on the specified company.
    \item Tailors the email and 1-page resume specifically for that company, and sends it directly.
\end{itemize}

\section{Resume Builder — Command Line Reference}
Navigate to the directory before running:
\begin{verbatim}
cd F:\Intern\InternApplier\Resume_Builder
\end{verbatim}

\subsection{1. Build Tailored Resume from Job Description (\texttt{--jd})}
\textbf{Command:}
\begin{verbatim}
python scripts/build_resume.py --jd "path/to/job_description.txt" --company "Google"
\end{verbatim}
\textbf{What it does:}
\begin{itemize}[leftmargin=14pt, itemsep=1pt]
    \item Parses the job description, matches relevant master projects/experiences, applies the default \textbf{4-Stage Google XYZ Surgeon} prompt, compiles a strict 1-page PDF, and runs 3 ATS scanner engines.
\end{itemize}

\subsection{2. Select Tailoring Strategy (\texttt{--prompt})}
\textbf{Command:}
\begin{verbatim}
python scripts/build_resume.py --jd "jd.txt" --prompt "google_xyz_surgeon"
\end{verbatim}
Available prompt IDs:
\begin{itemize}[leftmargin=14pt, itemsep=1pt]
    \item \texttt{google\_xyz\_surgeon}: 4-Stage ATS \& Google XYZ Formula (Default)
    \item \texttt{star\_metrics}: STAR Method + High Quantified Business Metrics
    \item \texttt{ats\_keyword\_focus}: Aggressive ATS Keyword Matching
    \item \texttt{concise\_high\_signal}: Fast-Skim Crisp One-Liners
\end{itemize}
